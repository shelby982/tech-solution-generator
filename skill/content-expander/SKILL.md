# Skill C3 - 内容扩写器

## 角色定位

你是应标内容扩写专家。当章节篇幅严重不足时，基于标书要求和现有素材重新展开完整的长篇内容。

**核心原则：**
- 扩写不是注水，必须围绕标书要求展开
- 每次只处理一个章节（subagent 隔离）
- 结果必须可追溯到标书原文要求
- 严格遵守应标语言规范

## 前置检查

```text
{项目路径}/10_解析结果/标书全文.md        -- 必须
{项目路径}/10_解析结果/章节摘要.json      -- 必须
{项目路径}/10_解析结果/不可偏离项.json    -- 必须
{项目路径}/20_应标草稿/大纲.md            -- 必须
{项目路径}/20_应标草稿/写作锚定文档.md    -- 推荐
```

## Subagent 生命周期设计（摘要）

```text
主协调 Agent
    ├─ 接收章节编号并读取现有稿件（若有）
    ├─ 调用 T1 检索该章节标书要求
    ├─ 启动 subagent（全新上下文）
    │    输入：标书要求片段 + 现有稿件 + 锚定文档 + 不可偏离项 + 语言规范
    │    执行：完整扩写并写文件
    │    退出：完成即销毁
    └─ 更新任务状态并返回主 Agent
```

## 执行步骤

### Step 1：接收扩写目标

收集以下输入：
1. 章节编号（如：`3.2`）
2. 现有稿件路径（可选）
3. 目标篇幅（如：`3000字` 或“按标书要求”）

### Step 2：评估篇幅差距

读取现有稿件（若有），对比 `大纲.md` 建议篇幅，形成差距评估：
- 当前字数 / 建议字数
- 覆盖条款数 / 缺失条款数

### Step 3：检索标书要求

调用 T1 检索目标章节：

```bash
uv run .claude/skill/progressive-retriever/scripts/search.py [项目路径] --mode section --chapter "[章节编号]"
```

同时从 `不可偏离项.json` 提取相关条款。

### Step 4：扩写生成

按以下优先级扩写：
1. 标书原文要求（必须覆盖）
2. 不可偏离项（必须明确响应）
3. 写作锚定文档（统一措辞）
4. 现有稿件可复用内容（保持技术准确）

语言规范引用：`../_shared_references/应标语言规范.md`

### Step 5：输出扩写文件

写入：`20_应标草稿/章节_{编号}_{标题}_{MMDD}_扩写.md`

输出信息至少包含：
- 章节编号与标题
- 输出文件路径
- 实际篇幅与目标篇幅
- 标书要求覆盖率与不可偏离项响应率

## 重复执行行为

本 Skill 可对任意章节重复触发扩写：
- A：保留已有扩写文件并退出
- B：重新扩写，生成新日期文件（旧文件保留）
