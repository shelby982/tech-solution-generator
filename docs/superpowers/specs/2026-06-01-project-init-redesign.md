# project-init 页面改版设计

**日期：** 2026-06-01  
**范围：** `frontend/project-init.html` 页面改版

---

## 目标

将 project-init 页面从简单的"上传材料 + 大纲文本"布局，改版为清晰展示应标提炼进度与各模块四字段内容（应标要求、应标重点、否决项、加分项）的工作台页面。

---

## 布局结构

三栏布局，嵌套在现有 `workspace-shell` 框架内，顶部流程 tab 不变。

```
┌──────────────────────────────────────────────────────┐
│  [项目名]  项目信息 | 材料撰写 | 审核导出   [主题/设置] │ ← 顶部 tab（不变）
├────────────┬─────────────────────────────┬────────────┤
│            │  [状态栏：进度 + 按钮]  sticky│            │
│  左侧      ├─────────────────────────────┤  右侧      │
│  材料面板  │                             │  窄边栏    │
│  260px     │  模块卡片列表（可滚动）      │  200px     │
│            │                             │            │
└────────────┴─────────────────────────────┴────────────┘
```

## 中间主区（flex: 1）

### 顶部状态栏（sticky，不随内容滚动）

| 状态 | 左侧 | 中间 | 右侧按钮 |
|------|------|------|----------|
| 空闲（未提炼） | 空 | 空 | 无 |
| 提炼中 | `正在提炼：[章节名]`（灰色小字） | 进度条 + `N/M 模块 · XX%` | `取消提炼`（次要） |

**卡片结构：**

## 数据流

### 现有接口复用
- `api.projects.get(projectId)` — 加载项目名
- `api.materials.list(projectId)` — 加载文件列表
- `api.blocks.list(projectId)` — 加载大纲模块列表
- `api.blocks.updateRequirement(blockId, value)` — 更新字段

### 新增字段需求
每个 block 需要返回以下字段（后端需确认或扩展）：
- `title` — 章节名（已有）
- `requirement` — 应标要求（已有，字段名复用）
- `key_points` — 应标重点（新增）
- `veto_items` — 否决项（新增）
- `bonus_items` — 加分项（新增）
- `extraction_status` — 提炼状态：`pending` / `extracting` / `done`（新增）

### 提炼进度 SSE
提炼过程通过 SSE 推送进度事件，格式：
```json
{ "type": "block_update", "block_id": "...", "status": "extracting", "progress_pct": 37 }
{ "type": "block_done", "block_id": "...", "key_points": "...", "veto_items": "...", "bonus_items": "..." }
{ "type": "extraction_complete", "total": 8 }
```
