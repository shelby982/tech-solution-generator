# 编辑界面：统一 AI 编制

## 问题与调整

| 原有问题 | 调整 |
| --- | --- |
| 快速草稿和多 Agent 是两套操作 | 移除快速草稿入口与前端调用，统一 AI 编制 |
| 生成结果在另一个区域，需要替换或追加 | 生成完成直接展示在正文编辑器，不再创建建议区域 |
| 全文格式、任务、正文上下堆叠 | Word 格式收进设置，正文成为主区域 |
| 编制依据、素材、专业分工混在一起 | 右侧按编制依据、本章素材、AI 编制切换 |
| 专业阶段名称不易理解 | 进度简化为编排内容、生成图文表、检查内容 |
| 历史任务占用正文空间 | 当前章最新任务优先，其他任务和模型设置默认折叠 |

## 交互规则

1. 左侧选择章节，中间显示章节名称、状态与正文。
2. 点击 AI 编制，在右侧查看编制说明并开始生成。
3. 任务只生成结果，不自动写入服务器正文；当前章节没有新编辑且正文版本未变化时，结果直接进入编辑器，作为未保存内容。
4. 核对后保存正文；需要时内容预览，再标记核对完成。
5. 导出本章、本组统一收在导出入口。

生成期间的人工修改不会自动覆盖。切换章节或离开页面后，任务仍在后台运行，可从任务中在编辑区打开结果。已有未保存编辑时禁止载入；先保存修改，再主动打开结果。重新加载页面不自动载入历史任务结果。

## 验证

- 前端回归 154 项通过，包含编辑冲突、切章、版本变化和三步进度映射。
- 浏览器核验三栏布局、页签切换、生成入口和真实任务进度。
- 真实模型完成「项目目标」章节，5238 字符直接显示在原编辑器；独立建议区域数量为 0，结果尚未保存到服务器正文。
- 不调整目录生成、模型编制、Word 交付的后端逻辑。
