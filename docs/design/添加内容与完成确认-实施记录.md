# 添加内容与完成确认

## 添加内容

- 在“更多 → 添加内容”中手动补充文字、表格或关系图，不调用模型。
- AI 编制期间与预览模式下隐藏该入口；事件处理同时校验运行状态。
- 分块编辑时在当前聚焦内容块后添加，保留分块模式；没有当前块时追加到末尾。
- 手动块有独立 ID、位置和编辑状态，编制快照更新或预览切换不会丢失。
- 普通 Markdown 编辑时仍按光标位置添加模板。

## 确认本章完成

- 先保存正文，再检查运行状态、待补充标记和已有 AI 检查意见。
- 正文为空、AI 正在运行或当前编制结果仍有未完成图表时，不允许确认。
- 无待处理项时直接标记完成；有待补充项或检查意见时展示数量摘要，明细可展开，用户明确确认后标记完成。
- 确认是人工状态标记，不触发新模型调用，不自动修复内容，也不代表评分验收通过。
- 提交时核对正文 hash，防止确认期间正文被其他入口修改。
- 完成后再次编辑，前端立即回到待核对；后端以确认 hash 校验已保存版本。
- 保存和导出不以完成状态为前提。
