# 插入菜单 → 插入面板：信息架构优化

> 对象：工具条「插入 ▾」下拉（截图里三段式长列表）。
> 结论：**下拉不适合承载"选内容"** —— 它撑不住 3 类 × 数十条 × 需要预览的结构。
> 应改成**小弹窗 + 三个互斥页签 + 搜索 + 选中后预览再插入**。

---

## 一、现在的问题（按严重度）

| # | 问题 | 为什么是问题 |
|---|---|---|
| 1 | **长度失控**：12 个片段 + 2 个来源标题 + 3 组，菜单高到要滚动 | 下拉是"快速选一项"，不是"浏览清单" |
| 2 | **来源与片段混排**：来源标题（黑字一行）+ 片段（蓝色列表）没有容器边界 | 第二个来源从哪儿开始看不出来 |
| 3 | **片段不可区分**：只显示前 34 字，6 条看起来几乎一样 | 选择成本高，容易插错 |
| 4 | **只列 6 段**：40 段要看全部得跳去素材池 | 断流：为了选一句要换页面 |
| 5 | **空组占位**：没素材时"还没有素材…"占一块 | 空状态该轻，不该占版面 |
| 6 | **点了就插**：没有预览、没有出处确认 | 误插后要手删；出处信息丢失 |
| 7 | 文案过时："去右栏『素材池』上传"（页签已改名「素材」）| 指引失效 |

一句话：**下拉在做"选择器"的活，但它的结构只够做"命令菜单"。**

---

## 二、优化目标（三件事）

1. **一屏内能选完**：不滚动就能看到 3 类入口 + 当前分类的内容
2. **每条可区分**：片段带**来源 + 定位（第 N 条/小节标题）**，不是只有开头文字
3. **先看再插**：选中后显示**将插入的内容 + 出处**，确认才落地

---

## 三、新结构：插入面板（小弹窗）

```
┌ 插入内容 ─────────────────────────────────────────┐
│ [从官方来源] [从素材] [结构模板]        ← 三个互斥页签 │
│                                                   │
│ 搜索片段 / 关键词…              [来源：全部 ▾]      │
│                                                   │
│ ▸ 国家发改委…答记者问 · 政策解读        ← 来源分组（吸顶）│
│   ① 近日，中共中央、国务院印发《关于发展新质…         │
│   ② 问：习近平总书记提出发展新质生产力已有3年…       │
│   ③ 答：过去3年，全国上下认真学习领会…              │
│ ▸ 中共中央 国务院关于发展新质生产力的意见…            │
│   ① 发展新质生产力是推动高质量发展的内在要求…        │
│                                                   │
│ 已选：国家发改委… · 第 3 条                        │
│ 预览：答：过去3年，全国上下认真学习领会、坚决贯彻…    │
│                                  [取消]  [插入]    │
└───────────────────────────────────────────────────┘
```

### 3.1 三个页签的职责（互斥、完整）

| 页签 | 内容 | 结构 | 主操作 |
|---|---|---|---|
| **从官方来源** | 已接受的官方来源 + 其片段 | 来源分组（吸顶标题）→ 片段（序号 + 一行截断，悬停看全文）| 选中 → 预览 → 插入（自动带【来源】）|
| **从素材** | 本章已关联素材 | 每份素材一行：文件名 + 解析状态 + 动作（摘录 / 图片 / 表格）| 摘录选中后插入；图片/表格直接插入 |
| **结构模板** | 对比表 / 响应表 / 关系图 / 分点清单 | 每个模板一行：名称 + 一句话说明 + 「预览」| 选中 → 预览 → 插入 |

### 3.2 为什么用页签而不是长列表

- 三类内容的**使用频率差别大**（引用 > 素材 > 模板），页签让默认落点明确
- 每类内部规则不同（来源要分组、素材要状态、模板要预览）→ 用页签分开才好各自优化
- 页签是**互斥**的，永远不会出现"一屏三类混排"

### 3.3 关键细节

| 细节 | 做法 | 理由 |
|---|---|---|
| 片段标识 | `① 开头文字…` + 悬停全文 + 显示所属小节标题 | 让用户能区分"哪一段" |
| 搜索 | 输入即过滤（来源标题 + 片段正文）| 40 段也能秒找，不用跳去素材池 |
| 来源筛选 | 来源下拉（全部 / 指定来源）| 多个来源时收敛范围 |
| 空状态 | 只留一行提示 + 一个主操作（去上传 / 去添加来源）| 空组不占版面 |
| 选中态 | 底部一条"已选 + 预览 + 插入"| 先看再插，误插率最低 |
| 插入后 | 光标落在末尾 + toast 可 ⌘Z | 与现有行为一致 |
| 出处 | 来源片段插入时自动附 `【来源：标题（机构 · 日期）】` | 合规硬要求 |
| 定位 | 插入位置 = 当前光标 | 不需要再拖动 |

## 四、和现有体系的关系

- **与「素材」页签**：素材页签是"缺什么/有什么"（管理+发现）；插入面板是"现在往正文放一份"（动作）→ 两个入口，职责不重叠
- **与「待办」页签**：待办里的"缺来源"点进去 = 打开插入面板的「从官方来源」页签（同一动作的两个入口）
- **与计划面板**：计划说"要放什么"（交付物要求表格/图示），插入面板是"放进去"的动作

---

## 五、实施要点（前端为主，无需新接口）

| 项 | 改动 |
|---|---|
| 工具条 | 「插入 ▾」下拉 → 按钮「插入…」打开弹窗（或保留下拉箭头但只作为入口）|
| 新组件 | `openInsertDialog()`：三页签 + 搜索 + 列表 + 预览 + 插入 |
| 数据 | 复用 `citationInfo.rows`（含 segments）、`context.materials`、固定模板文案 |
| 文案修正 | "素材池" → "素材"（页签已改名）|

---

## 六、验收标准

1. 「插入」打开后是**弹窗**，含 3 个互斥页签，一屏可见
2. 「从官方来源」有搜索框；片段显示 `序号 + 一行截断`，同来源的片段在**同一分组**下
3. 选中片段后底部出现**预览 + 出处**，「插入」按钮才可点
4. 「从素材」列出本章素材，含 摘录/图片/表格 三个动作；无素材时只有一行提示 + 上传入口
5. 「结构模板」每项可预览
6. 插入后光标落在末尾、正文含 `【来源`（来源片段）
7. 不再出现「素材池」字样
