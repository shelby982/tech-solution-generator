## 三、未完全覆盖（如实说明）

### #11 设置持久化 🟡
v3 §6.3 明确"只有两层：项目默认 + 章节覆盖"，v2 的"本次覆盖"被删除。
所以"本次不污染默认"这条判据**不再适用**，替换为：
- 章节覆盖写 `/blocks/{id}/writing-settings` ✓
- 项目默认写 `/projects/{id}/writing-settings` ✓
- 刷新后仍在（SQLite 持久化）✓

### #15 llm_usage 行透传 🟡
`llm_usage` 表已加 `block_id / section / role` 三列，但实测仍为空：
LLM 客户端在**独立 task 上下文**上报用量，`contextvar` 不会跨任务传播。

**当前可用的留痕**
1. `call_site=chapter_sse_text`（能按来源归集费用）
2. 作业 `artifacts.sections`（能回答"哪一节用了哪个模型、多少字、多久"）
3. `block_revisions.summary` 带模型清单

**修法（下一步小改）**：在 `infra/llm/clients.py` 的 stream/generate 里显式接收
`extra={"block_id","section","role"}` 并原样塞进 usage 记录，不依赖 contextvar。
