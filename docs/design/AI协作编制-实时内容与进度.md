# AI 协作编制：实时内容与进度

## 交付行为

- 单一正文编辑区域；主编形成计划后，按稳定任务 ID 生成内容块。
- 正文 Agent 使用真实模型流式接口，增量文字定期持久化，前端读取后更新对应正文块，不模拟打字。
- 图示与表格先显示标题、用途和状态占位；产物完成即保存，原位替换，不等待其他 Agent。
- 专业 Agent 并行执行，共享主编计划、规范要求、上下文章节与已核对素材。
- 按主编顺序合稿，技术与合规审校分别记录完成状态和检查意见。
- 右侧展示内容交付数、图文表分项数量、Agent 当前任务及本章准备摘要；编排目的、依据与模型设置按需展开。

## 编辑与恢复

- 每个内容块独立维护人工修改和移除状态；后续模型更新不会覆盖已编辑块，也不会重新插回已移除块。
- 修改其他块不会阻止尚未修改的文字继续流式输出。
- 图表支持查看及 Markdown 编辑切换；正文持续可编辑。
- 未完成的图表不写入正式正文；进度和阶段产物保存在编制任务中。
- 保存、完成与导出检查未完成内容；已有服务器正文变化时提醒核对，不直接覆盖。
- 未保存正文及块级修改在当前浏览器会话保留；重新打开遇到本地草稿时优先保护本地草稿，不自动覆盖。
- 可停止任务，再重试未完成阶段；离开页面后后端继续，服务启动恢复活动任务。

## 当前边界

- 图示当前为关系链图，可复用 Word 图示交付链路；不是复杂架构图或图片模型生图。
- 合稿按主编任务顺序确定性组装，没有额外增加一次“主编润色”模型调用。
- 内容块稳定 ID 是编制任务内的粒度；全文仍通过现有 Markdown 与 Word 链路交付，不迁移既有正文。
- 前端通过短轮询获得已持久化流式快照；不是 SSE 推送。生成角色使用真实流式响应，不对完整结果做伪流式播放。
- 模型字段校验、素材图片范围和规范 ID 校验继续保留；模型检查分数不代表人工验收通过。
