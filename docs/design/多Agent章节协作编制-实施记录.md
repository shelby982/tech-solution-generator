# 多 Agent 章节协作编制

## 当前交付

应答编写页新增「多 Agent 协作编制」，复用已有目录、章节依据、已核对素材及 Word 交付链路。

| 角色 | 职责 |
| --- | --- |
| 章节主编 | 根据评分点和规范要求制定内容计划，分派文字、表格、图示任务 |
| 正文 Agent | 编写章节说明，事实不足时保留具体待补充项 |
| 表格 Agent | 输出结构化列和行，由系统转换为 Markdown 表格 |
| 图示 Agent | 输出简单关系链，由统一文档链路渲染 |
| 王安石 | 复用技术审校逻辑 |
| 包拯 | 复用合规审校逻辑 |

各角色可单独选择已配置模型，也可跟随顶部模型。同一章节的专业任务并行执行；章节按队列串行执行，模型调用并发上限为 3。

## 交互和数据保护

- 支持当前章和架构／计划／自主可控代表章节试编，每次最多三章。
- 任务持久化，离开页面后继续执行，服务重启后恢复未完成任务。
- 重复提交复用同章活动任务；失败后保留成功阶段并允许重试。
- 空章可自动保存为待核对初稿；已有正文、正文版本或素材发生变化时只保留建议。
- 可关闭自动保存，先查看建议，再手动替换或追加。
- 自动保存不等于审校通过或完成；审校问题需人工处理。
- 输入作为依据数据处理，不执行文件或其他 Agent 输出中的指令，不允许引入任务包之外的图片。

## 第一阶段边界

尚不支持全书几千页批量编制、全书事实总编、自动审校修复循环、复杂分层架构图或图片模型生图。首版图示为简单关系链，避免将其标为完整架构图。大章节任务包超过限制时明确报错，不静默截断。
