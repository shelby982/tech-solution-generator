# 片段生成逻辑方案（上传文件 / 联网搜索 → 片段）

> 问题：上传文件或联网搜索之后，**片段是怎么生成的**？这一块如何设计才合理。
> 本文只出方案（不改代码）。

---

## 一、先看现状：当前片段质量实测（1634 段 / 66 段）

| 指标 | 上传文件片段（1634） | 联网来源片段（66） |
|---|---|---|
| 平均长度 | 295 字 | 174 字 |
| **中位长度** | **87 字** ← 说明一半以上是碎片 | — |
| 最长 | **27,826 字** ← 一整章没切 | 403 |
| 最短 | **2 字** | 30 |
| < 60 字的片段 | **635 段（39%）** | — |
| > 800 字的片段 | **90 段**（其中 28 段 >2000 字）| 0 |
| 疑似目录行噪声 | 31 段 | — |
| 含表格 | 149 段 | — |

**结论**：现在的切片是"按文档章节标题切"，导致
- **要么太碎**（标题、目录行、页眉页脚都成了一段，占 39%）
- **要么太长**（没再往下切，最长 2.7 万字，无法作为"一个素材"）
- **没有类型**（条款/数据/资质混在一起，筛选和匹配都没法做）
- **表格被切断**

---

## 二、目标：片段应该满足什么

片段 = **素材的最小单位**（挑中它就是素材），所以要满足 4 条：

| 要求 | 具体标准 |
|---|---|
| **可引用** | 带位置：文件页码 / 网页 URL + 锚点；能显示"第 12 页" |
| **语义完整** | 不被切断：一句话/一个条款/一张表/一个列表项要完整 |
| **粒度合适** | 目标 200~400 字；下限 80；上限 800（整表/条款例外 ≤1200）|
| **可判断** | 带类型标签：条款 / 数据 / 资质业绩 / 政策法规 / 表格 / 噪声 |

---

## 三、生成逻辑：四层流水线

```
原料（PDF/Word/Excel/图片/网页）
   ↓ ① 结构解析
   ↓ ② 结构切分（一级）
   ↓ ③ 尺寸归一 + 语义兜底（二级）
   ↓ ④ 类型标注 + 质量过滤 + 去重
片段入库（候选）→ 用户挑选 → 素材
```

### ① 结构解析层（按文件类型拿结构，而不是纯文本）

| 来源 | 解析出的结构 |
|---|---|
| PDF | 页码 + 书签/目录 + 标题字号层级 + 表格区域 |
| Word | 标题样式层级（Heading1/2/3）+ 段落 + 表格 |
| Excel | 工作表 + 表头 + 行组（一个表 = 一个块）|
| 图片/扫描件 | OCR + 版面（标题/段落/表格）|
| 网页 | 正文抽取（去导航/广告/页脚）+ 标题层级 + 列表/问答 |

> 关键：**必须有"层级 + 位置"**，否则后面无法按章节导航、无法标页码。

### ② 一级切分：按结构边界切

- 有标题层级 → **按最小可引用结构单元切**：
  - 招标文件：按 `第X章 > 第X节 > 第X条`；一条 = 一个片段（条款完整）
  - 技术规范：按"功能点/指标条目"
  - 网页：按小标题 / 问答对 / 列表项
- 无结构（纯文本/OCR 差）→ 退化为"按空行 + 句号"切
- **每条片段继承**：所属章节路径（`第三章 > 3.2 > 3.2.1`）+ 页码

### ③ 二级处理：尺寸归一（解决"太长/太短"）

**太长**（> 上限）：
```
按"条款边界 > 段落边界 > 句号边界"依次切
· 绝不切断一句话
· 一张表整体保留（允许到 1200 字），超出则按行组切并复制表头
· 切出的子片段带序号（3.2.1-1 / 3.2.1-2），引用时显示"第 4 页 · 续 2"
```

**太短**（< 下限 80 字）：
```
· 若它是标题 → 与后续第一段合并（标题作为片段首行）
· 若是目录行/页眉页脚/页码 → 直接标 noise（不进候选）
· 若是一个独立短条款（如"3. 投标人资格要求"）→ 保留，但标 `is_heading`
```

### ④ 类型标注 + 质量过滤 + 去重

**类型标签（规则打标，可多标签）**

| 标签 | 判据 |
|---|---|
| `clause` 条款 | 含"第X条 / 应 / 须 / 不得 / 须提供" |
| `data` 数据 | 含数字 + 单位（%/个/项/人/万/元/天…）|
| `qualification` 资质业绩 | 含"资质/证书/业绩/合同/验收" |
| `policy` 政策法规 | 含《…》/ 法规名 |
| `table` 表格 | 含表格结构 |
| `heading` 标题 | 短且无句号 |
| `noise` 噪声 | 目录行（`……12`）、页眉页脚、页码、重复行、样本表 |

**质量过滤**：`noise` 不进候选列表（但在挑选器里可"显示噪声"开关下看到）。

**去重**：
- 同文件内：内容指纹 `sha1(去空白+去标点)` 相同 → 只留一条
- 跨文件/跨网页：同一指纹（如重复上传同一招标文件、同一网页多次抓取）→ 标"重复来源"

## 四、联网搜索的片段生成（单独说明）

```
抓取网页 → 正文抽取（readability 类算法）
   ↓
按语义块切：小标题 / 问答对 / 列表项 / 段落
   ↓ 单块 > 400 字 → 按句切，不切断
   ↓
打标签（clause/data/policy/table）+ 可信度（域名白名单 / 发布时间 / 作者）
   ↓
去重（同 URL、内容指纹）
   ↓
入库（片段带 url + 抓取时间 + 域名）
```

**特别注意**：
- 问答类文章 → 一问一答 = 一个片段（不要按段落切散）
- 政策原文 → 按"第X条"切
- 新闻 → 按段落切（每段独立可读）
- 导航/推荐位/评论区 → 直接丢

## 五、参数与可配置（默认值）

| 参数 | 默认 | 说明 |
|---|---|---|
| 目标长度 | 300 字 | 中文；可 200~400 |
| 下限 | 80 字 | 低于则合并或标 heading |
| 上限 | 800 字 | 表格/整条条款例外 ≤1200 |
| 重叠 | 0 | 不重叠（避免重复引用）；靠"条款边界"保证不漏 |
| 噪声策略 | 丢弃但可查 | 挑选器可切换"显示噪声" |

**不同文件类型用不同策略**（预设，用户可改）：

| 文件类型 | 切片策略 |
|---|---|
| 招标文件/技术规范 | 按章/节/条（条款完整优先）|
| 评分标准 | 按评分项（一条评分点 = 一片段）|
| 我方材料（合同/验收/资质）| 按证件/单据（一证一片段）|
| 网页/文章 | 按小标题/问答对 |
| Excel 表格 | 按表名 + 行组 |

## 六、重新解析（文件更新 / 换策略）

这是必须考虑的工程点：

```
重新解析时：
· 新片段按"内容指纹"与旧片段对齐
· 旧片段若被挑为素材（selected）且指纹仍存在 → **保留为素材**（映射到新片段）
· 指纹消失（内容被删）→ 已选素材标"已失效"
· 顺带更新 chapter_material_chunks 的引用（映射新 chunk_id）
```

避免"重新解析一次，用户挑的 18 段素材全没了"。

## 七、质量验收指标（可自动测）

| 指标 | 目标 |
|---|---|
| 平均片段长度 | 250~350 字 |
| 中位长度 | ≥150 字（现在 87 ✗）|
| <60 字片段占比 | **<10%**（现在 39% ✗）|
| >800 字片段占比 | **<3%**（现在 5.5% ✗）|
| 噪声片段占比 | <5% |
| 条款完整性 | 含"第X条"的片段里，95% 能独立读懂（人工抽 30 条）|
| 表格完整性 | 表格片段不被切断（抽查 20 张）|
| 检索可用性 | 搜"业绩"命中 ≥5 条相关片段（招标文件）|

## 八、分期实现

| 期 | 内容 |
|---|---|
| **C1** | 尺寸归一（长短两级处理）+ 噪声过滤（目录/页眉页脚）+ 内容指纹去重 |
| **C2** | 类型标注（clause/data/qualification/policy/table）|
| **C3** | 结构解析增强（PDF 书签/Word 标题层级/表格识别）|
| **C4** | 重新解析的指纹映射（保住已选素材）|
| **C5** | 不同文件类型的切片预设 + 参数可配 |

## 九、需要你确认

1. **片段目标长度**：300 字（可 200~400）是否合适？（招标条款可能更长，我们允许到 1200）
2. **噪声片段**（目录/页眉页脚）：直接丢弃（推荐）还是保留在"显示噪声"里可查？
3. 重新解析时**已选素材是否保留**？（推荐保留，靠指纹映射）
