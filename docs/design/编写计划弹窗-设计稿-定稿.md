# 编写计划弹窗 · 设计稿（定稿）

> 本稿只保留**一种**方案（已按推荐项定稿），可直接进入实施。
> 设计原则一句话：**先告诉编写人员"现在该做什么"，再让他查看"要写什么"，参考信息一律折叠。**

---

## 一、信息层级（三层）

| 层 | 内容 | 可见性 |
|---|---|---|
| **L1 结论** | 章名 · 计划篇幅 · 已写 · 待办数 · **一个主操作** | 常驻，1~2 行 |
| **L2 行动** | ① 待办清单（每条一个按钮）② 交付物明细（只展开第一项未达标） | 常驻，展开 |
| **L3 参考** | ③ 依据与标准 ④ 写法要点 ⑤ 子节统筹（父章/目录） | 折叠 |

---

## 二、线框（叶子章 · 单列）

```
┌──────────────────────────────────────────────────────────────────┐
│  本章编写计划                                              ×      │
├──────────────────────────────────────────────────────────────────┤
│  项目背景现状目标                                                 │
│  计划 12 页 · 3000 字 ｜ 已写 5634 字 ⓘ ｜ 待办 3 项               │
│                                               [ 去补 3 项 ]       │
├──────────────────────────────────────────────────────────────────┤
│  ① 待办（3 项）                                                   │
│                                                                   │
│   1  补 1 份我方材料（数据/案例/业绩）              [ 去找素材 ]   │
│   2  政策 / 标准 / 数据处补【来源】标注              [ 去补来源 ]   │
│   3  字数超计划 88%（5634 / 3000 字）                [ 去精简 ]     │
│                                                                   │
├──────────────────────────────────────────────────────────────────┤
│  ② 交付物 ｜ 3 项不足 · 2 项未写                          [改要求]  │
│                                                                   │
│  ▾ [文字] 写清楚「背景」        833 字 · 已写 231 · 不足           │
│      必答：项目由来与建设动因 / 政策依据（引用文件与要求）          │
│      [ 定位到正文 ]                                                │
│  ▸ [文字] 写清楚「现状」        833 字 · 已写 268 · 不足           │
│  ▸ [文字] 写清楚「目标」        833 字 · 已写 308 · 不足           │
│  ▸ [表格] 政策依据映射表        300 字 · 未写                      │
│  ▸ [图示] 趋势或现状对比图      200 字 · 未写                      │
│                                                                   │
├──────────────────────────────────────────────────────────────────┤
│  ③ 依据与标准   评分点 1 · 招标条款 3 · 失分点 4            ▸     │
│  ④ 写法要点     结构 / 段落 / 落点                          ▸     │
├──────────────────────────────────────────────────────────────────┤
│                                    [ AI 编制本章 ]   [ 关闭 ]      │
└──────────────────────────────────────────────────────────────────┘
```

**宽屏（≥720px）不启用两栏**：保持单列竖读，减少视线跳转；两栏留作后续可选项。

## 三、区块规格（逐块：内容 / 交互 / 空态）

### L1 结论条

| 元素 | 内容 | 规则 |
|---|---|---|
| 章名 | `title` | 17px 深色 |
| 形态标签 | `叶子章`（不显示）/ `父章 · 只写总述` / `目录节点` | 淡色小徽标 |
| 数字行 | `计划 {pages} 页 · {total} 字 ｜ 已写 {written} 字 ⓘ ｜ 待办 {n} 项` | `ⓘ` 悬浮显示口径说明（"按小节标题能对应到交付物的是 807 字，逐项'已写'为估算值"） |
| 主操作 | `去补 {n} 项` / `去写总述` / `看子节进度` / `去生成正文` | 唯一 primary 按钮，文案随状态变（见第四节） |

**空态**：`待办 0 项` 时数字行显示「待办 0 项 · 可以生成」，主操作变「去生成正文」。

### ① 待办（L2 主区块）

- 每条 = `序号 + 一句话行动 + 一个按钮`，一行一条，最多 5 条。
- 排序（固定优先级）：**卡生成 > 质量 > 格式**
  1. 素材缺口（缺料就写不出）
  2. 内容未达标（某项交付物未写/不足）
  3. 【来源】标注
  4. 字数超/欠
  5. 图表缺失
- 动作映射：
  | 待办类型 | 按钮 | 行为 |
  |---|---|---|
  | 素材缺口 | 去找素材 | 关弹窗 → 打开官方来源抽屉（带本章上下文） |
  | 内容未达标 | 去补/去生成 | 关弹窗 → 定位本章 → 触发 AI 编制本章 |
  | 来源标注 | 去补来源 | 关弹窗 → 打开官方来源抽屉 |
  | 字数超 | 去精简 | 关弹窗 → 定位本章（提示"精简至 X 字"） |
  | 图表缺失 | 去出图 | 关弹窗 → 定位本章 |
- **空态**：`✓ 没有待办，可以直接生成`（一行绿字）。

### ② 交付物（L2 明细）

- 块头：`交付物 ｜ {n} 项{ · 不足 x · 未写 y}` + 右侧 `[改要求]`（低频，弱化样式）。
- 每项 = 一行摘要：`▸/▾ | [类型] 标题 | 目标 X 字 · 已写 Y 字 · 状态`
- **只展开第一项未达标**：展开态额外显示 `必答：…` + `[定位到正文]`；其余折叠。
- 状态词只出现一次（行末），描述行不再重复"不足"。
- **空态**：`本章还没有交付物（系统未匹配到要求）` + `[改要求]`。

### ③ 依据与标准（L3 折叠）

- 摘要行：`评分点 1 · 招标条款 3 · 失分点 4`（无条款时省略该段）
- 展开后：
  - 评分点：`名称（10 分）` 一行
  - `满分档要求 ▸`（二级折叠，避免长段占位）
  - `本章承接的招标条款 3 条 ▸`（二级折叠）+ `[重新用 AI 匹配]`
  - 失分点：一行橙字

### ④ 写法要点（L3 折叠）

- 摘要行：`结构 / 段落 / 落点`
- 展开后：`结构：A → B → C`、`段落：每段首句给判断…`、`[看写作规范（全局）]`

### ⑤ 子节统筹（父章 / 目录节点，L2）

- 块头：`子节统筹 ｜ 7 节 · 共 84 页`
- 每行：`标题 | 进度条 | 已写 X/Y 页 | 有正文/未开始`，**整行可点** → 打开该节计划
- 父章额外一行提示：`本章只写总述（300–500 字）：先全貌 → 3 个结论 → 子节索引`

## 四、状态 → 界面 映射矩阵

| 章节状态 | 数字行 | 主操作 | 区块可见性 |
|---|---|---|---|
| 叶子章 · 有待办 | 计划/已写/待办 N | 去补 N 项 | ①②③④ |
| 叶子章 · 无待办 | 同上 · 待办 0 | 去生成正文 | ①②③④ |
| 父章 · 总述未达标 | 总述 X/400 字 · 子节 N 个 | 去写总述 | ①（含"写总述"待办）②③④⑤ |
| 父章 · 总述已达标 | 总述 384/400 字 · 子节 N 个 | 看子节进度 | ①②③④⑤ |
| 目录节点 | 下辖 N 节 · 计划 X 页 · 已写 Y 页 | 看子节进度 | ⑤③（无①②④） |
| 加载失败 | — | — | 一行错误 + `[重试]` |

```jsonc

  "pages": 12,
  "word_plan": { "total": 3000, "written": 5634, "percent": 188, "advice": "" },

  "todo": [                                  // ← 新增：统一待办（后端算好优先级）
```

## 六、交互细节

| 交互 | 定义 |
|---|---|
| `ⓘ` 口径说明 | hover/点击显示：`全章已写 {total} 字；能按小节标题对应到交付物的是 {detected} 字，逐项"已写"为估算值，以正文为准` |
| 折叠 | 统一 `▸ / ▾` + 摘要必带数字；点击整行摘要展开 |
| 定位到正文 | 关闭弹窗 → 选中该章 → 编辑器滚动到与交付物标题**最相关的小节标题** |
| 去精简 | 关闭弹窗 → 选中该章 → 提示「目标 3000 字，当前 5634 字，建议精简 X 字」（不自动改正文） |
| 主操作 | 唯一 primary；其余按钮均 secondary/链接样式 |
| Esc / × | 关闭（不保存任何状态） |

## 七、视觉规格（最小约束）

| 元素 | 规格 |
|---|---|
| 章名 | 17px / 600 / `#0f172a` |
| 数字行 | 13px / `#334155` / 等宽数字 |
| 块标题 | 13px / 600；摘要 11.5px / `#64748b` |
| 交付物标题 | 12.5px / 500；数字 11.5px / `#64748b` |
| 状态色（唯一强调） | 不足/超 = `#b45309`；未写 = `#94a3b8`；达标 = `#15803d` |
| 间距 | 块间 10px；行内 6px；块头与内容 6px |
| 按钮 | 主操作一次只有一个；行内按钮用链接样式（11.5px，蓝色） |

---

## 八、明确不做

1. **不做两栏布局**（保持竖读）
2. **不做"自检"独立块**（未过项全部并入待办）
3. **不在正文里展示长段评分标准**（进二级折叠）
4. **不自动改正文**（精简/生成都要用户点）
5. **不做打分/完成度百分比**（只有"待办 N 项"这个可执行计数）

---

## 九、验收标准（实施后逐条对照）

- [ ] 打开弹窗 3 秒内能说出"我还缺几项、该点哪个按钮"
- [ ] 状态词在界面上只出现一次（行末）
- [ ] 折叠块不展开也能判断要不要看（摘要带数字）
- [ ] 除主操作外，所有动作都在它对应的对象旁（行内/块头）
- [ ] 父章/目录节点不出现"交付物/字数"这类不适用的块
- [ ] 加载失败时有一行错误 + 重试按钮，不白屏
