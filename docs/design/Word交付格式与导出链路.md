# Word 交付格式与导出链路

## 产品规则

- 编写前确认招标规定的文档类型、目录和固定表单。编写阶段保存正文内容及来源关联。
- 交付格式可以提前选择，也可在导出前调整；格式切换不重新生成正文。
- 导出时使用该次任务固定的正文、图片、结构模型和 DOCX 样式模板。
- 内置格式提供排版预设，不代表已识别招标规定的表单，不包含企业封面或任意 DOCX 模板导入。

## 实现

```text
章节树与 Markdown 正文
    → markdown-it-py CommonMark 语法树
    → 文档块模型 version 1
    → 固定正文、图片和 DOCX 模板字节及 SHA-256
    → DOCX 样式映射
    → Word 文件可下载
    → LibreOffice 隔离排版
    → PDF 预览可查看
```

### 统一结构

文档块包含段落、小标题、列表层级、表格单元格、图片引用、关系图和代码块。正式章节层级来自章节树；正文最浅的小标题位于当前章节的下一级，Word 最深使用 Heading 9。

内容预览和新导出任务共用后端解析模型。外部图片地址被拒绝，图片须先上传本项目；解析阶段不访问网络。Markdown 代码块中的关系图语法保持代码，不误识别为图形。

### 基础模板

`backend/infra/docx/templates/` 中维护 standard、formal、compact 三份真实 DOCX 样式模板。模板负责页面、正文、标题、题注、表格、页码及域更新设置；不保存项目正文。

模板修改后以新 SHA-256 标识。已有任务读取快照中的模板字节，不读取新模板文件。可通过 `scripts/build_response_templates.py` 重建默认模板；手工调整模板样式后，无需修改 Markdown 正文。

### 排版预览

预览读取该次任务生成的 DOCX 字节，经 LibreOffice 转换为 PDF；每次转换使用独立用户目录，最多同时执行一个预览。Word 渲染与预览状态分别保存。预览缺少引擎、超时或失败时，已生成的 Word 仍可下载，预览可单独重试。

开发机需要安装 LibreOffice，可通过 `DOCX_PREVIEW_SOFFICE` 指定可执行文件。macOS 使用任务临时 fontconfig 扫描系统中文字体，并提供宋体、仿宋的预览回退；DOCX 字体声明不变。实际字体替代和分页可能与 Microsoft Word 不同，正式交付需在目标 Word 环境核对。

全文导出包含目录域，Word 打开后可更新目录和页码。PDF 为兼容排版预览，不宣称与 Microsoft Word 像素一致。

## 界面

- “Word 模板”改为“交付格式”，选项直接显示字体和字号。
- 显示纸张、行距与边距，展开可查看应用时机和模板版本。
- 支持预览固定样张或下载 Word 样张。
- “内容预览”查看当前编辑内容，不保存正文，也不模拟分页。
- 导出任务完成后，分别显示 Word 下载与排版 PDF；预览失败不会隐藏 Word 下载。
