# 编辑页：操作与助手职责收敛

## 产品问题

原界面把章节身份、保存状态、AI 操作、编辑方式、插入工具和草稿恢复分成多条常驻区域；正文工具栏的 AI 按钮实际只打开右侧面板，右侧又有生成按钮，两个入口含义重叠。切回编辑没有清除预览提示，异步预览请求也可能在用户切回编辑后重新打开预览。

## 当前结构

| 区域 | 职责 |
| --- | --- |
| 标题 | 当前章节名称及保存／核对状态 |
| 正文工具栏 | 唯一 AI 编制入口、保存、编辑／预览切换 |
| 更多 | 插入表格／关系图、标记核对完成、导出本章／本组 |
| 右侧依据 | 本章评分、规范原文及编排建议 |
| 右侧素材 | 本章材料上传、核对、引用与映射 |
| 右侧编制进度 | 同一次编制任务的准备摘要、Agent 分工、交付数量与检查意见 |

正文 AI 按钮直接启动本章任务，自动打开右侧进度；运行中禁用重复启动，完成后显示重新编制。右侧不再单独生成，不是第二套工作流。模型设置和历史任务收起。

## 状态与草稿

- 编辑和预览互斥显示；预览异步请求失效后不能重新覆盖编辑视图。
- 去掉重复预览提示、常驻插入说明和重复阶段进度条。
- 普通未保存草稿在服务器基准未变化时自动恢复，标题轻提示；只有版本冲突需要人工选择。
- 无修改时保存禁用；输入后标记未保存。
- 不重写已有正文中的标题或内容，不改变生成与 Word 导出逻辑。

## 验证

- 前端 158 项测试通过。
- 新增视图互斥与草稿恢复／冲突规则测试。
- 浏览器核验：只有一个编制入口，右侧无重复生成按钮；预览隐藏编辑器，切回后内容一致且无过期提示；插入工具条已移除。
