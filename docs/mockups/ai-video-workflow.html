AI 视频工作流：四类路线，一张选型图

按「与真实产品的一致性 × 自动化程度」分类，而不是按"是否用了大模型"。ToB 产品宣传片要的是真实 UI、可信证据、多版本迭代——落点在高控制、高自动化这一格。

选型矩阵

REALITY × AUTOMATION
与 真 实 产 品 的 一 致 性 →
自 动 化 程 度 →
仅实拍

传统实拍 / 人工剪辑

实拍 + 剪辑师

品牌大片质感最好，但单条 8k–20k、迭代慢，多版本要重做。

我们只用它拍 3 个实拍镜头（纸、笔、合上标书）
推荐

程序化渲染 + 真实录屏

Remotion · Revideo · Playwright · agentic-product-demo

脚本/分镜 JSON 驱动模板渲染；产品界面用 Playwright 录真实交互，或用代码复刻 UI。

一套模板出 9:16 / 16:9 / 15s / 多语言；改版可一键重录
现状

截图 / PPT 拼贴

手工截图 + 剪辑软件

把界面截图贴进时间线，加淡入淡出。快，但不像"产品在动"，也没有证据感。

就是我们现在 animatic 阶段的做法，只能验证节奏
不可用于界面

一键成片 + 生成式 b-roll

MoneyPrinterTurbo · ShortGPT · ComfyUI / Wan2.1

文案 → TTS → 库存素材自动合成；生成模型做氛围空镜。快，但与真实产品无关。

生成 UI 会篡改表格与中文，只做转场/空镜
纵轴：与真实产品的一致性（上高下低）；横轴：自动化程度（右高左低）。右上角才是我们要去的地方。

推荐管线：脚本驱动 + 程序化渲染

8 STEPS
01

主张与脚本

LLM + 人定稿

一句话主张、旁白、逐镜头文案。

02

script.json

唯一事实源

镜头 / 字幕 / 时长 / 素材类型 / 证据点。

03

素材采集

Playwright + 实拍

自动录真实 UI；补 3 个实拍镜头。

04

模板渲染

Remotion

一套组件出多比例、多时长。

05

配音

CosyVoice / ElevenLabs

逐句生成，便于对齐与改词。

06

字幕对齐

WhisperX

词级时间戳，替代手工卡点。

07

后期封装

auto-editor + ffmpeg

去静音、响度标准化、导出。

08

质量门

LLM 初检 + 人工终审

术语 / 数字 / 脱敏 / 字幕校对。

边界：生成式模型只做 b-roll；产品界面一律"录屏或代码复刻"，否则会出现表格错位、中文乱码、按钮幻觉——这是 ToB 宣传片最不可接受的事故。
